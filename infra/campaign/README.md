# 팬 코스 준비

`seed_fan_routes.py`는 창원 원희 코스와 강릉 슬기 코스의 **일반 팟**을 각각 하나씩 만들고, 팟마다 가상 멤버 5명을 넣는다. 별도 캠페인 전용 팟 유형이나 복사 이력 테이블은 사용하지 않는다. 같은 이름의 가장 오래된 팟에 정확히 같은 멤버가 있으면 재사용하고, 다르면 중단한다.

| 팟 | 멤버와 장소 |
| --- | --- |
| 원희 따라 걷는 창원 · 팬 코스 | 창원레일—창원역, 짬뽕메이트—백년옛날짬뽕, 반송미식—반송칼국수, 반송산책—반송여자중학교, 롤러별—제이씨락롤러장 |
| 슬기 따라 걷는 강릉 · 팬 코스 | 강릉칼국—형제칼국수, 마젤산책—르봉마젤 소품샵, 감자메이트—삶은감자, 강문파도—강문해변, 회센타팬—옛소라회센타 |

사진을 받기 전에는 장소 기록을 생성하지 않는다. 사진을 등록할 때 각 멤버의 해당 장소 기록에 연결한다. 반송여자중학교는 장소 언급만 하며 학교 출입이나 학생 촬영을 유도하지 않는다.

운영 서버에 `copyParty` API가 배포된 뒤, DB 접속 환경변수와 지갑을 준비해 스크립트를 실행한다. 출력된 초대코드는 공유 전에 보관한다. 팬 앱은 이 코드를 `copyParty`에 전달해야 개인별 복사 팟이 만들어진다. 기존 `joinParty`는 원본 팟에 직접 참여한다. `copyParty`는 같은 사용자의 반복 복사와 정원 6명인 원본의 복사를 허용한다.

복사 성공 후 Discord 알림은 `DISCORD_PARTY_COPY_WEBHOOK_URL`로 보낸다. 비어 있으면 기존 `DISCORD_KPI_WEBHOOK_URL`을 사용한다.
